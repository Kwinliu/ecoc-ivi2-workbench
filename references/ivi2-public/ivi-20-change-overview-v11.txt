INTRODUCTION 
With effect from 5th July 2026 the eCoC (IVI) will become mandatory for the 2018/858 vehicle categories. It’s 
important to note that the new IVI version and guideline related to the IVI 2.0 also apply to the 167/2013 and 
168/2013 vehicle categories. Also, not all changes have been included in this document. This applies in particular 
to those amendments which have been the subject of discussion. In the appendix "Overview transition From IVI 
1.10-To-2.0 v1.0" sheet more changes are indicated at field level. 
*) Changes made after publication of the first draft IVI version 2.0. Other previously implemented changes are 
also included.

COMBINING FIELDS TEST RESULTS (N)OVC AND OTHER VEHICLE 
Some fields are either for (N)OVC or other vehicles in the IVI message. For instance charge sustaining only for 
plug-in hybrid (OVC) or Co2combined only for NOVC vehicles. Field will not be combined to one tag. Main 
reason is that if these fields should be combined the definition is only clear when using other information in the IVI 
message. The tag itself does not define the content anymore. Having the fields separated is also in line with the 
legislation. If necessary the ICM can check the correct usage of the fields.

IVI CONTENTCHECK MODULE (ICM) 
The new version of the ICM will check if fields are relevant for a specific vehicle category. If not 
applicable the ICM will reject the IVI file. 
For instance if a Colour is stated for the VehicleCategory M2, the file will be rejected. 
Also if an indicator field is relevant for the VehicleCategory it has to be present with a Y of N. 
For instance for M1 PureElectricVehicleIndicator is mentioned on the CoC, for Petrol vehicles 
the tag has to be present with value “N”.
